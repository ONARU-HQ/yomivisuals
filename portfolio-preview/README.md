# Yomi Visuals — Animated Portfolio Preview

This is a standalone static preview under `portfolio-preview/`. It is kept separate from the production TanStack/Lovable application at the repository root.

## Design
- Dark cinematic editorial website with animated entrance and reveal transitions
- Responsive Portraits, Brands, Weddings and Lifestyle filters
- Accessible keyboard-enabled image lightbox
- Motion reduction support for reduced-motion preferences
- Links to the original Pixieset galleries and YV Studios booking

## Photography transfer status
The approved archive has 353 original photographs. A curated selection of 23 optimized WebP assets exists in the separately prepared local bundle `Yomi_Visuals_Vercel_Portfolio.zip`, **but those binaries are not yet uploaded to this GitHub branch**. The preview temporarily references existing images from `src/assets/` on the same repository's main branch to avoid broken images. These placeholders must be replaced with the approved 23 images before any portfolio launch. Do not assume the placeholders have accurate client attribution.

## Deploy
Vercel project: `yomi-visuals-portfolio`
Framework: Other / static
Root directory: `portfolio-preview`
No environment variables, CMS, or backend access are required for the static preview.

## Review gate
Do not merge this feature branch into `main`, publish to `yomivisuals.com`, or represent this preview as the finished 23-image gallery until the final assets have been transferred and verified.
